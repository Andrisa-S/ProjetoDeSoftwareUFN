# 🏗️ Projeto de Software — UFN

Repositório com conceitos e exercícios desenvolvidos durante a disciplina de Projeto de Software do curso de Ciência da Computação na **Universidade Franciscana (UFN)**, unindo teoria de arquitetura de software com prática de desenvolvimento.

O repositório é organizado por tema, separando a documentação conceitual da parte prática de implementação de um CRUD.

---

## 📁 Conteúdo do repositório

### 📐 Arquitetura de Software
Documentação com conceitos fundamentais de arquitetura de software, incluindo boas práticas de organização, planejamento e estruturação de sistemas.

### 🔄 Metodologia Ágil — Scrum
Material sobre o framework **Scrum**, cobrindo papéis, eventos e artefatos utilizados na gestão ágil de projetos de desenvolvimento de software.

### 💻 CRUD — Java e HTML
Implementação prática de operações de **CRUD** (criar, ler, atualizar e excluir), aplicando os conceitos de arquitetura estudados com back-end em **Java** e front-end em **HTML**.

---

## 🎯 Conceitos estudados

- Fundamentos de arquitetura de software
- Planejamento e organização de projetos com **Scrum**
- Papéis, eventos e artefatos ágeis
- Desenvolvimento de operações de CRUD integrando back-end e front-end
